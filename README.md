# Kutubxona

Android-приложение **Kutubxona** (библиотека).

## Установка

1. Скачайте файл [`Kutubxona_1.apk`](Kutubxona_1.apk).
2. Разрешите установку из неизвестных источников в настройках Android.
3. Откройте скачанный APK и установите приложение.

## Файлы

- `Kutubxona_1.apk` — собранное приложение.
